# LaSt-ViT 阅读汇报

## 论文信息

- 标题：Vision Transformers Need More Than Registers
- 作者 / 会议或期刊：CVPR
- 链接：[https://arxiv.org/pdf/2602.22394](https://arxiv.org/pdf/2602.22394)

## 一句话概括

这篇文章关注的是模型的本质，发现并解决了ViT中存在的懒惰聚合问题，并引导模型真正去关注重要区域。

## 方法要点

### 研究综述

ViT在大规模数据上进行了预训练之后，能够为下游任务提供通用的特征表示。然而人们广泛的观察到了ViT存在“伪影”的问题，这里的“伪影”指的是模型关注到了不该关注的地方，比如将背景当成了物体，导致在进行分割或定位时效果不好。之前的研究发现出现类似噪点，解决方法大多都只是修掉或者忽视，认为是数据问题，但是作者认为这个是一个系统问题。

作者通过实验对比CNN与ViT的物体框定区域，得到一个结果，这种伪影的产生实际来源于一种“懒惰聚合”的行为，在全局注意力机制和粗粒度语义监督的驱动下，ViT会寻找一个捷径，在训练初期利用语义无关的背景图去表示全局语义。这样导致的后果显而易见，将真正图像中的前景物体，也就是语义描述的物体进行了一定程度的忽视，而将图像中的背景，尤其是在其占据区域较大时为了快速误差下降被迫赋予了全局语义。

这里有两个推手，一个是全局注意力，让背景信息能够到处乱跑；另一个是粗粒度监督，标签欠缺像素级的语义，导致背景也在学习。作者做了假设以及相关实验，引入了量化指标：框内点(PiB指标)以及Patch Score([CLS]&patch_token余弦相似性关系)。实验表示：

> 自然图像本身就包含许多与主要物体无关的背景块。在仅有图像级监督的情况下，模型缺乏空间指导，因此倾向于通过背景证据来编码全局语义（即懒惰聚合）。这是一个非常可怕的发现。通常我们认为，得分最高的Patch应该是物体的关键部位（比如猫头）但作者说：把这些最高分的Patch删掉（Mask掉），模型居然还能认出这是只猫！意味着那些得分最高的Patch其实是背景（比如草地、天空）。因为背景面积大、特征明显，模型只要看到背景就能猜出类别，根本不需要看前景物体。这就是极致的“懒惰”。

> 全局依赖关系使得ViT能够利用这些无关的背景块作为捷径来表示全局语义。在缺乏块级标注的情况下，ViT可能会在训练初期采用一种懒惰聚合策略，即将少量的前景语义扩散到背景中。文中也验证了减少全局依赖确实能减轻伪影现象。这个其实还比较容易理解，哪怕前景只有一点点，通过注意力机制，这点信息瞬间就被稀释并扩散到了所有背景块里。于是，所有背景块都觉得自己代表了“这只猫”。

作者希望能有办法强迫模型少看背景，多看前景。那么解决方案是选择性的将图块特征整合到[CLS]中，从而减少背景主导的捷径的影响。这里不同于传统的ViT将patch_token整合到[CLS]中，也不同于DINO将[CLS]再作用于patch_token，而是一种选择性的选取图块特征。

### 分析过程

1. 提出评价体系与衡量标准：

首先，作者引入了patch score。作者想要体现不同模型之间不同的真正关注的区域，为了在不同架构和预训练设置之间进行统一比较，引入了Patch Score评价体系，将其定义为每个图像块与全局表示之间的相似度，目标是为了展示局部特征和全局特征像不像。ViT有一个显式的[CLS] token，专门用来代表整张图；CNN通过全局平均池化之后得到一个向量作为全局特征。然后将这个全局token和某个背景块的特征向量进行余弦相似度的计算。

其次，作者提出PiB打分体系(Point-in-Box benchmark)，基于patch score，我们能通过确定得分最高的区域是否对应前景物体来评估伪影，但是我们要去看这些位置是否真正落在物体上。作者定义patch score就是落在前景框内的图像所占的比例。

2. 模型到底在关注什么？

Q1: [CLS] token到底在看哪里？

作者做了一个很简单的实验，根据归一化的patch-score分布进行图像的遮蔽。比如某个Patch得分高，那就将其涂黑，看模型是否还能认出图中的物体。如果涂黑了“高分区域”，模型就不认识了，说明它真的在看那里。如果涂黑了“高分区域”，模型还能认出来，说明它在撒谎——那些高分区域其实没那么重要。

实验结果很惊人，前景块集中在低得分区域，而背景块占据了高分区域，这和我们的传统认知相违背。作者发现移除高分块并不会损害准确率，甚至可以略微提高，相反，移除低分快会使准确率急剧下降

在输入图像中遮蔽背景块几乎不影响分类性能，然而这些区域的特征响应却与编码类别语义的 [CLS] token 高度相关，这表明前景信息在训练过程中已经被传播到了背景中。这就是“懒惰聚合”的铁证。模型为了省事，把前景的特征（比如“有毛”、“有四条腿”）广播到了所有背景块上。所以当你问 [CLS] 在看哪里时，它看着满屏的背景，因为背景里全是它学到的“捷径信息”。

Q2: 什么时候产生这种不好的现象？

作者追踪了全流程，ViT的PiB分数持续处于低位，尽管分类准确率不断提高，这意味着ViT是从一开始就每学会定位物体，他的准确率是靠别的背景刷上去的，而没有真正理解物体。

CNN就是个老实人，ViT就是个投机分子

3. 粗粒度语义监督下的粗暴实验

我们可以怀疑是标签太粗糙导致模型偷懒去看背景，那我们如果减少背景数量，是否有助于模型真正理解物体本身？

作者通过增加嵌入模块Pemb(.)中使用补丁减少背景的普遍性，这个逻辑就是原来可能是16x16的格子，但是如果变为28x28的格子，patch总数变少了，这样，背景在整个序列中的占比就下降了，前景物体的相对重要性就上升了。

实验表明，在扩大补丁大小并将背景令牌比例减少约10%后PiB分数的确有增加，模型的确更多的关注到了物体本身。这说明背景太多是一个问题。但是这里分类率暴跌，这说明这种方法仍旧不可靠，因为会牺牲模型的核心分类能力。

4. 抵消全局注意力机制的影响

由于全局注意力机制的存在，会导致ViT全局依赖，关注过多。作者为了逐步限制全局注意力机制，作者在不同层中用窗口注意力替换全局自注意力。事实证明的确有效，但是如果都换成窗口注意力，分类效率暴跌。

这里在不同层使用窗口注意力的意思其实很简单：ViT 的 patch token 都是平铺的 dim 维度的内容，不过这只是数据的存储格式；窗口注意力改变的是数据之间的交互方式。我们都知道ViT有很多层，每一层都对应着不同的意义，浅层看纹理边缘，深层看语义，物体部件；这里选取其中的n层作为测试，本来ViT得到dim的过程就是从一个图中根据patch_size=kernel_size=stride进行移动得到特征向量的CNN过程，原来全局注意力可以任意位置的patch进行信息交互，但是加上窗口注意力之后就变成了只能在区域内信息交互；这也导致了如果全局都使用窗口注意力就退化成类似CNN的网络。

### 解决方案

作者这里主要运用的就是一个逆向思维，就是既然去除低分数区域之后的效果会有明显变化，那么作者就通过一个傅里叶变换，区分开了什么是高频区域什么是低频区域
