# DuSt3R 阅读汇报

## 论文信息

- 标题：DUSt3R: Geometric 3D Vision Made Easy
- 作者 / 会议或期刊：CVPR
- 链接：[https://arxiv.org/abs/2312.14132](https://arxiv.org/abs/2312.14132)

## 一句话概括

DuSt3R 是一项针对多视角重建任务的革新性工作，旨在解决在无约束环境下进行3D重建时，如何获得相机内参以及位姿信息的核心痛点。

### 摘要

所谓“前馈”，指的就是一次前向传播，直接输出结果。首先是动作上的前馈：在深度学习中，数据从输入层经过隐藏层，最后到达输出层的过程，称为前向传播。传统方法就像一个学生在做一个很难的数学题，需要不断验算和修正错误，反复迭代优化，直到算出最终答案，这在计算上非常耗时；而前馈方法就像一个经验丰富的专家，通过了大量的训练积累之后，看一眼图像，凭借积累的海量数据训练的神经网络，不需要反复验算，直接就能得到最终结果。然后是路径上的前馈：单向直通，不走回头路。传统算法中系统会不断根据后面的结果反过来调整前面的参数，而前馈网络中单项传递。

DuSt3R颠覆了传统多视角立体重建的范式，传统方法通常需要精确的相机参数来将像素点三角化到3D空间，而DuSt3R采取了截然相反的策略：**1. 摒弃了相机参数依赖**，它不依赖任何先验的相机标定信息或视角位姿，实现了真正意义上的“无约束重建”；**2. 回归点图**，将成对的重建问题转化为点图的回归问题，从而绕开了传统投影相机模型的硬性约束；**3. 统一单目与双目重建**，这种方法统一了单目、双目重建；**4. 全局对齐策略**，当输入超过两张图片时，它会采用一种简单而有效的全局对齐策略，将所有成对的点图表达在同一个参考坐标系下。

DuSt3R基于Transformer编码器和解码器，这使得它可以利用强大的预训练模型，直接提供场景的3D模型和深度信息，可以无缝地从生成的模型中反向恢复出像素匹配点、相对相机位姿和绝对相机位姿。
