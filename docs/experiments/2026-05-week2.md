10. 对齐流程
> estimate_overlap_transform.py

主要思路：（1）同一物理场景有两段Stream3R重建，世界原点不同，但场景几何应只差一个刚体变换p001=Rp000+t；(2)纯几何ICP一方面其本身的误差较大，另容易被行人、车辆等动态物体带偏，脚本用PCD里seg语义ID，从seg_000里每个点只在seg_001里相同seg标签的点中找最近邻，相当于建立对应关系。（3）算法流程（函数estimate_pair_transform）：通过过滤ignore_seg，对两边点云体素下采样，并限制点数上限；对seg_001按每个语义标签见cKDTree，如果点数太少的标签就跳过；初值R=I，t=两点云的质心差。（4）输入PCD格式，输出qx qy qz qw x y z标准的四元数+平移

命令行用法：
python v4/estimate_overlap_transform.py --pair-root "e:/stream3r_across/v4/011200-011202" --frames 011200 011201 011202 --out "e:/stream3r_across/v4/011200-011202/transform_seg000_to_seg001.txt" --voxel 0.025 --iters 12 --ignore-seg 0 255 --seed 0

参数含义：
--pair-root：根目录，其下必须有子目录 seg_000/、seg_001/，且同名帧的 {帧ID}.pcd 成对存在。

--frames：一个或多个帧 ID（与文件名一致，不含 .pcd），按顺序逐帧估计变换并各写一行。

--out：输出 txt 路径；目录不存在会自动创建。

--voxel：体素网格边长（米）。>0 时做下采样；越大点越少、越快但细节越少。

--iters：语义约束迭代次数（每轮：NN → 剔外点 → Kabsch）。

--ignore-seg：可多个整数：不参与配准的语义 ID；默认 [0]（常用来去掉背景或未标注类）。

--seed：随机种子；体素/子采样里有随机性，固定种子可复现。

函数里还有内部常量（命令行未暴露），例如 max_pts、max_nn_mult、距离分位数等，用来控制速度和鲁棒性；若报「有效匹配过少」，脚本会提示调大 voxel 或检查语义/路径。
